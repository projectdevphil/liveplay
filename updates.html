MTV Live Cessation of Broadcast

MTV Live channel will permanently cease all broadcast transmission worldwide (excluding the U.S. feed) effective January 1, 2026.

The final day of programming for MTV Live will be Tuesday, December 31, 2025. Following the closure, the channel will be removed from the channel list starting on January 1, 2026.

Latest Build: v1.0.7

Version 1.0.7 CURRENT

  • New Integration: Implemented a native Litestream Speed Test utility, effectively replacing the external 'SpeedUp' platform. Powered by Project Dev and utilizing Netflix's fast.com API, this built-in feature provides users with a seamless, accurate assessment of their internet connection, specifically optimized to gauge streaming performance and stability.

Version 1.0.6

  • UI Optimization: Refined the visual dynamics of the Featured Slider with advanced transition logic.
  • New Feature: Introduced the **Top 10 Live TV Channels** ranking system powered by Redis.
  • Documentation: Incorporated a comprehensive **Version Details** log.

Version 1.0.5

Integrated a real-time Stream Status monitor. The "Live" sensor utilizes active health-checking to automatically turn the indicator red, visually alerting users immediately if a specific stream source is offline or experiencing downtime.

Version 1.0.4

Deployed a centralized Updates tab within the main navigation menu. This hub provides users with critical information, including channel advisories, system notifications, and overall platform status reports.

Version 1.0.3

Incorporated network diagnostic tools. This integration allows users to seamlessly access tools for testing latency (ping), upload bandwidth, and download speeds without leaving the ecosystem.

Version 1.0.2

Added a gateway to the Stream Tester, a specialized sister platform utility created by Project Dev. This feature enables advanced users and developers to validate external stream links (supporting HLS and MPD with DRM keys) or upload and execute playlist configurations directly.

Version 1.0.1

Implemented a monetization framework featuring pre-roll advertisement functionality, allowing short promotional content to display prior to the initialization of the live channel stream.

Version 1.0.0 (Initial Release)

Official platform launch introducing core capabilities from Project Dev. Features include comprehensive channel and genre search engines, curated featured slides, and a streamlined navigation architecture for live content viewing.
