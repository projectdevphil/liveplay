Changelog

Version Details

Latest Build: v1.0.9

Version 1.0.9 CURRENT

  • Visual Update: Updated the channels logo container aspect ratio from Square with rounded corners to a clean Circle aspect ratio.
  • Minimize Player Enhancement: Updated the Mobile/Tablet minimize player exit button to a standalone design, ensuring a cleaner interface and easier navigation control.
  • Border Refinements: Adjusted the border radius of containers within Channel Lists, Featured Slides, Floating Menu, and Subpages from 15px to 25px.
  • Platform Rebranding & Cleanup: Rebranded the "Updates" section to "Changelog" to prioritize feature release history, and removed the Service Status module.
  • Service Discontinuation: Removed the Stream Tester shortcut. The Stream Tester utility has been permanently discontinued, with no current plans to bring the utility back online.
  • Ad-Free Playback Optimization: Completely removed the pre-roll video advertisement system that previously initiated prior to loading live channel streams. This change eliminates initial playback latency, resulting in significantly faster channel load times and a more seamless, uninterrupted viewing experience.
  • Database Migration: Transitioned the backend storage for the Top 10 Live TV Channels ranking system from Vercel (Upstash Redis) to Cloudflare's D1 (SQLite) databases to align with our platform's infrastructure transition from Vercel to Cloudflare.

Version 1.0.8

  • System Enhancement: Upgraded real-time status monitoring. Channel indicators now automatically turn red if a stream is down. The new Service Status module dynamically calculates platform health by evaluating the percentage of operational channels and displaying a color-coded indicator (Green, Yellow, Orange, Red) to reflect real-time stability.
  • Mobile Search Gesture: Optimized the mobile search layout. The search container now dynamically appears directly below the search bar for improved visibility and ease of use.

Version 1.0.7

  • New Integration: Implemented a native Liveplay Speed Test utility, effectively replacing the external 'SpeedUp' platform. Powered by Project Dev and utilizing Netflix's fast.com API, this built-in feature provides users with a seamless, accurate assessment of their internet connection, specifically optimized to gauge streaming performance and stability.

Version 1.0.6

  • UI Optimization: Refined the visual dynamics of the Featured Slider with advanced transition logic.
  • New Feature: Introduced the Top 10 Live TV Channels ranking system powered by Vercel (Upstash Redis).
  • Documentation: Incorporated a comprehensive Version Details log.

Version 1.0.5

  • Stream Status: Integrated a real-time stream status monitor that utilizes active health-checking to automatically turn the indicator red, alerting users immediately if a specific stream source is offline.

Version 1.0.4

  • Platform Directory: Deployed a centralized Updates hub within the main navigation menu, consolidating channel advisories, system notifications, and status reports.

Version 1.0.3

  • Diagnostics: Incorporated utility tools for testing network latency (ping), upload bandwidth, and download speeds directly inside the application.

Version 1.0.2

  • Stream Tester: Implemented a gateway to validate external streaming configurations (supporting HLS/MPD with DRM keys) and execute custom playlists.

Version 1.0.1

  • Ad Integration: Implemented monetization framework capabilities supporting short pre-roll advertisement playbacks before loading live channel feeds.

Version 1.0.0 (Initial Release)

  • Official Launch: Released core framework utilities including specialized search interfaces, genre filters, interactive featured content carousels, and main media playback configurations.
